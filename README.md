# Gatherly — Enterprise Event Management Platform

Gatherly is a next-generation event management suite built with React, Node.js, Express, and SQLite.

## Features
- **Interactive Event Hub**: Browse, filter, search, and manage global summits, keynotes, and workshops.
- **Dynamic Calendar**: Schedule and manage events with date inspector and quick 1-click removal.
- **Operational Tasks & Master Agenda**: Track team execution, progress sliders, and session timelines.
- **QR Certificates & Pass Generator**: Custom certificate studio with real-time canvas preview and PNG export.
- **Voice & AI Assistant**: Integrated AI support for venue bookings, ticketing, and platform navigation.
- **Finance & Sponsors**: Sponsorship tier calculator, contract management, and revenue analytics.

## Production Build & Run
```bash
# Install dependencies & build client
npm install
npm run build

# Start backend server
npm start
```
